# 小熊识字森林

新增适合 3—6 岁家庭共玩的主题课程：4 组能力路径、24 节主题课、96 个互动练习、6 篇原创短故事，以及每课一项亲子表达和生活延伸活动。

- 3 岁左右：两图选择、听词回应、熟悉生活与口语表达。
- 4 岁左右：图字联结、观察常见字形、在生活中发现文字。
- 5 岁左右：词语搭配、短句理解、方位、三步排序与情境表达。
- 6 岁左右：短文信息、原因线索、故事排序和生活标牌。

年龄仅供选课参考，所有课程可自由进入，不设识字量或入学能力门槛。可使用故事与选项朗读，观察记录会区分朗读支持；练习结果不等同独立识字或阅读能力。亲子表达由家长确认参与，不录音、不自动评分。课程完成标记仅存在浏览器本地，详细答题记录不上传。

设计方向参考教育部《3—6岁儿童学习与发展指南》与幼小科学衔接指导；课程、题目、故事和年龄路径为本项目自编，并非官方评估工具。

适合亲子陪伴的中文识字小游戏，包含五个自选阶段、220个字词、童趣合成配音、翻卡配图和庆祝效果。

字卡会眨眼、弹跳入场，翻面后可以点图片听讲解、看图片跳舞。点小熊可以听玩法或击掌；每次尝试都会在进度小路上开一朵花。互动不会重复计分，支持系统的减少动态效果设置。

点击开始后播放声音，每轮10题。结果仅用于家庭观察，不是标准化测评。

自由练习的答题状态仅保存在浏览器当前页面；主题课程完成标记保存在本机浏览器。均不上传答题记录。

站点由静态HTML和音频文件组成。打开index.html或使用静态HTTP服务器即可运行。音频采用云夏合成男声。
